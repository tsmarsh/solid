The language

A program is a few (def name value) lines and then one solid. Everything is a list: the first word is the operation. Comments start with ;. Nothing else can run: there is no file access and no loop except repeat.

Operations
FormMakes
(cube x y z) (cube-centered x y z)a box from the origin, or centred on it
(sphere r [level])a sphere of 8·4level faces (level 0 to 5, default 3)
(cylinder h r [r2] [segments])a cylinder, cone (r2 = 0) or frustum on the z axis (3 to 128 segments)
(polygon x y, x y, ...)an outline; either winding; may not cross itself
(extrude h outline hole...)the outline lifted by h, with holes cut
(revolve segments profile)a profile (x = radius, y = height) turned about the z axis
(polyline x y z, ...) (polyline-closed ...) (arc r degrees segments) (bezier x0 y0 z0, ... x3 y3 z3 segments) (helix r pitch turns segments-per-turn) (helix-axial pitch turns segments-per-turn) (join path path ...)a path for a sweep. An arc is in the xy plane starting at (r 0 0), a helix is about the z axis; 360 degrees or a closed polyline makes a closed path
(sweep path outline hole...) (sweep-with twist-degrees end-scale path outline hole...)the outline carried along the path (a rotation-minimising frame, so it does not flip), with flat ends on an open path. A bend tighter than the outline is wide, or coils closer than it is thick, is an error that says so. helix-axial keeps the outline in the plane through the z axis (x = distance from the axis, y = height), like revolve that also rises
(twist-extrude h twist-degrees slices outline hole...)the outline lifted by h and turned through the angle
(thread d pitch length segments clearance) (nut d pitch height across-flats segments clearance)an ISO metric thread (major diameter d), and a hex nut for it whose thread is clear of a screw of the same d and pitch by the clearance. Set a nut a whole number of pitches up a screw to mesh them
(screw-hex d pitch across-flats head-height shank thread segments) (screw-cylinder d pitch head-diameter head-height shank thread segments)a screw: head below z = 0, a plain shank, then the thread
(translate x y z s) (scale x y z s) (rotate x y z s) (mirror nx ny nz s)a moved, stretched, turned (degrees, about x then y then z) or mirrored solid
(union a b ...) (difference a b ...) (intersection a b ...)the booleans, taken from left to right
(edges-where solid test) (faces-where solid test) (rims-where solid test) (count selection)a selection: the edges, faces or circular rims of the solid for which the test holds, found from the geometry every time the program runs, never by number. A selection that matches nothing is an error that says so.
(fillet solid selection r [segments]) (chamfer solid selection d)the selected edges or rims rounded with radius r (the arc in segments steps) or cut off by d. Convex edges lose material, concave edges gain it. Edges that meet at a box corner get a sphere patch there; a corner that is not a box corner is refused with the reason, and so is a radius that does not fit.
tests on edges(convex) (concave) (angle-above deg) (angle-below deg) (the turn at the edge: 0 flat, 90 for the edge of a cube) (length-above l) (length-below l) (parallel x y z)
tests on faces(facing x y z) (area-above a) (area-below a)
tests on rims(circular) (radius-above r) (radius-below r) (on-axis x y z) (the axis passes through the point) (on-cylinder x y z dx dy dz r) (the axis passes through the point along the direction, with radius r). A rim also answers the tests on edges.
tests on either(x-above v) (x-below v) (x-between lo hi) and the same for y and z (every point of it lies so), (on-top) (on-bottom) (on-left) (on-right) (on-front) (on-back), (on-plane nx ny nz d), (near x y z r) (within r of the point), (touching selection)
(and test ...) (or test ...) (not test)tests combined
(repeat i n body)the union of body for i = 0 … n−1
(let name value body) (def name value)names; numbers use + - * / min max abs sqrt sin cos pi

Limits: 8000 characters, 24000 faces per boolean, 20000 evaluation steps, 45 seconds per render. This is the built demo of a solid-modelling library written in fibber; the library's source is not published yet.
