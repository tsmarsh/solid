The language

A program is a few (def name value) lines and then one solid. Everything is a list: the first word is the operation. Comments start with ;. Nothing else can run: there is no file access and no loop except repeat.

Operations
FormMakes
(cube x y z) (cube-centered x y z)a box from the origin, or centred on it
(sphere r [level])a sphere of 8·4level faces (level 0 to 5, default 3)
(cylinder h r [r2] [segments])a cylinder, cone (r2 = 0) or frustum on the z axis (3 to 128 segments)
(polygon x y, x y, ...)an outline; either winding; may not cross itself
(extrude h outline hole...)the outline lifted by h, with holes cut
(revolve segments profile)a profile (x = radius, y = height) turned about the z axis
(translate x y z s) (scale x y z s) (rotate x y z s) (mirror nx ny nz s)a moved, stretched, turned (degrees, about x then y then z) or mirrored solid
(union a b ...) (difference a b ...) (intersection a b ...)the booleans, taken from left to right
(repeat i n body)the union of body for i = 0 … n−1
(let name value body) (def name value)names; numbers use + - * / min max abs sqrt sin cos pi

Limits: 8000 characters, 24000 faces per boolean, 20000 evaluation steps, 45 seconds per render. This is the built demo of a solid-modelling library written in fibber; the library's source is not published yet.
